# 快速入門

只要幾個步驟，一塊 ESP32 就會成為門戶 [portal.idryer.org](https://portal.idryer.org/) 和 iDryer 應用程式中的裝置：連上網路、綁定到你的帳戶、顯示自己的資料，並接收來自卡片的命令。

你需要：一塊 ESP32-C3 板（DevKit、Super Mini 或相容板）、一條 USB 線、PlatformIO、一支裝有 iDryer 應用程式的手機、一個 2.4 GHz 的 Wi-Fi 網路，以及門戶帳戶。
