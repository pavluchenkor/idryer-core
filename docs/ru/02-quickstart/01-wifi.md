# Wi-Fi

В прошивке нет пароля от сети. Устройство без сохранённой сети ждёт настроек; получив их, сохраняет сеть в NVS и дальше подключается само. Сеть — только 2,4 ГГц.

## Приложение iDryer (ESPTouch)

Основной путь: приложение передаёт сеть по воздуху, без проводов.

1. Телефон — в той сети, где будет работать устройство.
2. **Подключить новое устройство** → шаг **Wi-Fi**: проверьте название сети, введите пароль, нажмите **Подключить устройство**.
3. Приложение передаёт настройки до 90 секунд и показывает **Устройство подключено**.

При неверном пароле устройство снова ждёт настроек — повторите шаг.

## По USB через Improv

Пока у устройства нет сети, ядро слушает протокол Improv на последовательном порту.

1. Подключите плату по USB.
2. Откройте [improv-wifi.com/serial](https://www.improv-wifi.com/serial/) в Chrome или Edge (Web Serial в Safari и Firefox не работает), нажмите **Connect** и выберите порт платы.
3. Введите название сети и пароль.

Порт в это время занят Improv, поэтому лог появляется только после подключения к сети. Закройте монитор порта, пока работает Improv.

## В коде — для стенда разработчика

```cpp
void setup() {
    // Только для стенда разработчика: сеть сохраняется в NVS, если её там ещё нет.
    s_link.seedWifiCredentialsIfEmpty("my-ssid", "my-password");
    s_link.begin();
}
```

`seedWifiCredentialsIfEmpty()` записывает сеть, только если в NVS её ещё нет; `setWifiCredentials()` перезаписывает всегда. Вызывайте до `begin()`.

!!! warning
    Не выпускайте прошивку с паролем в коде: он попадёт каждому, кто её скачает.
