# Rychlý start

V několika krocích se z ESP32 stane zařízení na portálu [portal.idryer.org](https://portal.idryer.org/) a v aplikaci iDryer: připojí se k síti, spáruje se s vaším účtem, ukáže svá data a přijme příkazy ze své karty.

Budete potřebovat: desku ESP32-C3 (DevKit, Super Mini nebo kompatibilní), USB kabel, PlatformIO, telefon s aplikací iDryer, síť Wi-Fi 2,4 GHz a účet na portálu.
