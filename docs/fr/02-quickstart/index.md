# Démarrage rapide

En quelques étapes, un ESP32 devient un appareil sur le portail [portal.idryer.org](https://portal.idryer.org/) et dans l'application iDryer : il rejoint le réseau, s'associe à votre compte, affiche ses données et reçoit les commandes de sa carte.

Il vous faut : une carte ESP32-C3 (DevKit, Super Mini ou compatible), un câble USB, PlatformIO, un téléphone avec l'application iDryer, un réseau Wi-Fi 2,4 GHz et un compte sur le portail.
