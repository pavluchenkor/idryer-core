# Ajouter un nouveau produit basé sur idryer-core

Ce guide sert à créer un nouveau produit basé sur `idryer-core`: sécheur de filament, bloc chauffant, éclairage, capteur ou autre module. Il montre ce qui reste dans la bibliothèque et ce qui appartient au code du produit.
