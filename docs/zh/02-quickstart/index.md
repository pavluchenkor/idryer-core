# 快速入门

只需几步，一块 ESP32 就会成为门户 [portal.idryer.org](https://portal.idryer.org/) 和 iDryer 应用中的设备：连上网络、绑定到你的账户、显示自己的数据，并接收来自卡片的命令。

你需要：一块 ESP32-C3 板（DevKit、Super Mini 或兼容板）、一根 USB 线、PlatformIO、一部装有 iDryer 应用的手机、一个 2.4 GHz 的 Wi-Fi 网络，以及门户账户。
